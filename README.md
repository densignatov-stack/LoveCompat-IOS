# LoveCompat 2.0 — Flutter

Cross-platform rebuild of LoveCompat 2.0 for Android and iOS.

The UI and deterministic calculation are based on the working Android 2.0 build. The app is an entertainment test, not a scientific assessment.

## iOS

Open this project on a macOS runner with Flutter installed. `flutter build ios --no-codesign` validates the iOS build without signing. Installing on a physical iPhone requires Apple signing/developer credentials.
